# CompTIA Security+ (SY0-701) Study Tracker

An interactive 60- or 90-day study pathway mapped to the official CompTIA Security+ SY0-701 exam objectives (v5.0).

**Open the tracker:** https://mrmeaswell.github.io/secplus-sy0-701-tracker/

## How to use
1. Choose the 60- or 90-day pathway and set your start date.
2. Work through each week's tasks and check them off.
3. Rate your confidence (1-4) on each of the 28 objectives.
4. Log practice exam scores. Aim for three full practice exams at 85%+ before booking the exam.

Progress saves in your browser. Use **Export** to back it up and **Import** to restore it on another device.
